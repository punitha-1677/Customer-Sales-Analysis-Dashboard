# Customer-Sales-Analysis-Dashboard
This project is an interactive Excel dashboard created to analyze customer sales performance and business insights. The dashboard provides detailed analysis of total sales, early sales trends etc.. The project was built using Excel with Pivot Tables,  Charts, KPI Cards, and Slicers to create a dynamic and user-friendly reporting dashboard.  
Customer Sales Analysis Dashboard.

Key Features:
• Total Sales, Profit, and Customer KPI Cards
• Product-wise Sales Analysis
• Monthly Sales Trend Analysis
• Payment Method Analysis
• Customer Rating Analysis
• Year-wise Sales Performance
• Interactive Slicers for filtering data

Tools Used:
• Microsoft Excel
• Pivot Tables
• Pivot Charts
• Slicers
• Conditional Formatting

This dashboard improves data visualization and helps businesses make better data-driven decisions.
